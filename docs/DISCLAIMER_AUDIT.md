## 3. 断定的・誘導的になり得る表現

検索語: 必ず／確実／絶対／儲か／おすすめ／リターン／元本保証／お得 ほか。

- **問題なし（詐欺・誤解を戒める文脈）**: クイズの誤答選択肢と解説（`question_seed_*`、`roleplay_scenario.dart`）。「絶対儲かる」「元本保証で高利回り」を疑うよう教える内容。
- **文言を和らげる候補**:
  - `glossary_term.dart:96`「確実に貯まりやすい」→「貯まりやすい」
  - `question_seed_savings.dart:35`「余りを貯めるより確実に貯まります」→「貯まりやすくなります」
  - `investment_simulation_pattern.dart:69`「高いリターンを狙いたい人向け」→「値動きが大きいパターン（リスクも大きい）」。特定の人への運用の推奨と読める余地を減らす
- **「おすすめ」**: 通知チャンネル「おすすめ通知」、診断の「あなたへのおすすめ」は、節約のヒント・制度の確認のお知らせ。特定の金融商品の推奨には使っていない（現状のコード上）。

## 4. 金融庁・弁護士に確認したい論点（たたき台）

1. 無料／有料の投資シミュレーション（仮想運用・NISA/iDeCo概算）が、教育目的の一般情報として、投資助言・代理業の登録を要しない範囲に収まっているか
2. 診断結果から出す節約・制度のアドバイスが、個別の金融商品の推奨に当たらないか
3. ベンチマーク統計は、総務省家計調査等を参考にした近似値（実データの集計ではない）。画面に「公表統計を参考にした近似値・参考値」と明記済み。ただ「同じ年代・年収帯」と書いてあるため、実際の同年代の集計と誤認されないか。実データ化する場合は、5人以上のグループでのみ集計するなど、同意・匿名化が要る（コードのコメントにも記載あり）
4. 課金表示（月額1米ドル、広告なし＋出力などの全機能）の表示・解約案内
5. 収集データ（支出、レシート・給与明細の画像）の扱い。プライバシーポリシー、Play のデータセーフティ
