## データの収集・共有の一覧

| データの種類 | 収集 | 共有 | 目的 | 根拠（コード上の事実） |
|---|---|---|---|---|
| メールアドレス | する（任意） | しない | アカウント管理 | Google ログインを選んだ場合のみ。Firebase Auth が保持。匿名ログインではメールなし |
| ユーザー ID | する | しない | アプリの機能・アカウント管理 | Firebase Auth の uid、Firestore の `users/{uid}`、Analytics のユーザープロパティ `user_id` |
| 名前・ニックネーム | する（任意） | しない | アプリの機能 | 世帯リーグのニックネーム（`memberNicknames`）、世帯名 |
| その他の金融情報 | する | しない | アプリの機能 | 支出額、予算、貯蓄・貯蓄目標、仮想投資、レシートの金額・カテゴリ・日付、ふるさと納税の寄附記録（Firestore） |
| 購入履歴 | する | 共有（RevenueCat＝サービス提供者） | アプリの機能（課金状態の管理） | RevenueCat SDK。購読状態の判定 |
| 写真・動画 | **収集しない** | — | — | レシート・給与明細は端末内の文字認識（ML Kit）で処理。画像そのものは送信せず、Firestore に保存するのは画像のパス文字列のみ（要確認: パスが端末固有のため実質無意味） |
| アプリの操作（アプリ内の行動） | する | しない | 分析 | Firebase Analytics のイベント（クイズ完了、ミッション完了 など） |
| クラッシュログ・診断 | する | しない | 分析・アプリの安定性 | Firebase Crashlytics |
| デバイス ID その他の ID | する | **共有** | 広告・分析 | 広告 ID（AdMob）。Firebase のインストール ID |
| 大まかな位置情報 | 要確認 | 要確認 | 広告 | AdMob が IP から推定する可能性。位置情報の権限は宣言していない |

「共有」の定義（Play）では、サービス提供者（データ処理者）への送信は共有に含めない。広告配信（AdMob）は、広告 ID を第三者へ渡すため「共有」にする。

## アカウント・データ削除（Play の要件）

Play は、アプリ内でアカウントを作れる場合、次の2つを求める。
1. アプリ内でアカウント（と関連データ）の削除を開始できる導線 → **実装済み**
2. Play Console に、アプリ外（ウェブ）からも削除を依頼できる URL → **未整備（あなたの作業）**

実装済みの内容（アカウント画面 →「アカウントとデータを削除」）:
- 再認証（Google ログインの場合）→ Firestore のデータ削除 → ログインアカウント削除 → 端末内データ削除
- 削除対象: `users/{uid}` 配下8コレクション、ストリーク、旧構造のレシート、世帯グループからの脱退（ニックネーム・貢献額も削除）、週次チャレンジの参加
- 削除されないもの: 世帯グループ文書そのもの（残るメンバーの共有データ。合計貯蓄額を含む）、Analytics・Crashlytics に送信済みの利用状況（Google 側の保持期間に従う）、Play の購読（利用者が Play で解約する。ダイアログで案内済み）
- **実機での動作確認は未実施**（特に Google 再認証）

残りの作業:

## 広告に関する宣言

- 広告を含む: はい
- 広告 ID の使用（Play Console の「広告 ID」宣言）: はい。目的は「広告またはマーケティング」「分析」。`google_mobile_ads` が `AD_ID` 権限を自動で追加する。
- ユーザーの同意（UMP）: EEA・英国向けに実装済み。同意が得られなければ広告をリクエストしない。
